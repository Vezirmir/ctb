# CTB — база компаний для B2B-мероприятий

Веб-платформа для хранения компаний по отраслям и странам, их e-mail, контактных лиц,
истории переписки, мероприятий и встреч. Интерфейс на английском и турецком
(переключатель языка вверху справа).

## Что уже есть

- **Компании**: страна, отрасли, сайты, телефоны, теги, заметки, результаты сверки с анкетой и проверки сайта.
- **E-mail адреса** с источником (список / сайт компании / почта CTB), счётчиком отправленных писем,
  датой последнего письма и отметками «ответил» и «проверить привязку». Адреса без компании
  хранятся там же, с группой.
- **Контактные лица**: руководство, закупки, продажи.
- **Мероприятия, участники и встречи** между компаниями.
- **Фильтры и поиск**: по стране, отрасли, «ответил CTB», тегам и мероприятию; поиск по названию,
  e-mail, ФИО, сайту и телефону.
- **Импорт из Excel** (кнопка «Import from Excel» в списке компаний): zip-архив с папками
  `Отрасль/Страна/файл.xlsx`, как в папке `2026`, или отдельный .xlsx. Повторный импорт
  не создаёт дублей.
- **Экспорт выбранных компаний в Excel.** Экспортированный файл можно снова импортировать.
- **Проверка e-mail** (кнопка «Check unchecked addresses» в списке e-mail или действие над
  выбранными): ошибки в написании, опечатки в популярных доменах (gmial.com, mai.ru), домены,
  которые не существуют или не принимают почту. Неверные адреса не используются при отправке.
  Из командной строки: `python manage.py check_emails` (`--all` — проверить всё заново).
  Проверка не гарантирует, что ящик существует: это видно только по возврату письма.
- **Регистрационная анкета** для мероприятия: публичная страница без входа, на EN и TR.
  Общая ссылка есть на странице мероприятия, а в шаблоне приглашения плейсхолдер
  `{registration_link}` даёт каждой фирме личную ссылку с уже заполненными данными. Фирма
  указывает данные и участников. Если такая фирма уже есть (по названию, e-mail или сайту),
  данные дополняются, иначе создаётся новая. Приглашение получает статус «Registered»,
  участники видны на вкладке «Participants», новые регистрации — в меню «Registrations»
  и на дашборде.

## Доступ для коллег

Группы создаются автоматически при `migrate`:

- **Read only · Sadece görüntüleme**: только просмотр компаний, e-mail, контактов, мероприятий,
  приглашений, встреч и шаблонов. Нет импорта, экспорта, кнопок звонка или письма, расписание
  только для просмотра.
- **Editor · Düzenleyici**: всё то же, плюс добавление, изменение, удаление и экспорт в Excel.

Как завести коллегу: Access → Users → «+», задать логин и пароль, сохранить. Затем на странице
пользователя в поле Groups выбрать нужную группу и сохранить. Доступ к панели (staff status)
включится сам. Чтобы читателю разрешить выгрузку в Excel, добавьте ему право
«Can export companies and e-mails to Excel». Пользователи, группы и настройки почты видны
только администратору (superuser).

## Запуск на своём компьютере

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows  (Linux/macOS: source .venv/bin/activate)
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser  # логин и пароль администратора
python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и войдите.

Импорт из командной строки (папка, zip или .xlsx):

```bash
python manage.py import_companies "C:\Users\...\CTB\2026"
```

## Настройки для сервера (переменные окружения)

| Переменная | Значение |
|---|---|
| `DJANGO_SECRET_KEY` | длинная случайная строка |
| `DJANGO_DEBUG` | `0` |
| `DJANGO_ALLOWED_HOSTS` | домен, например `ctb.example.com` |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | `https://ctb.example.com` |
| `DATABASE_URL` | например `postgres://user:password@host:5432/dbname` |

Перед запуском на сервере выполните `python manage.py migrate` и `python manage.py collectstatic`,
затем запустите приложение: `gunicorn config.wsgi`.

## Переводы

Тексты интерфейса на турецком лежат в `locale/tr/LC_MESSAGES/django.po`. После правок их нужно
скомпилировать: `python scripts/compile_translations.py`.
